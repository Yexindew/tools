# SKILL.md — 问卷分析助手

## 适用场景

用户上传问卷数据文件（Excel/CSV），需要进行数据清洗、基础分析、交叉分析、开放题归纳，并将结果写入学城文档。

触发词：上传问卷文件、分析问卷、问卷结果、帮我跑问卷、问卷数据分析。

## 完整交互流程

### 阶段0：收到文件后

**第一步：清洗确认——作答时间**

```
📋 问卷已读取
├─ 原始数据：XX 条
├─ 作答时间 < 40s：XX 条（建议剔除）
├─ 作答时间最短：XXs，最长：XXs
└─ 建议剔除后剩余：XX 条

是否按默认阈值（40s）剔除？
[1] 确认，剔除 XX 条
[2] 修改阈值（告诉我新的秒数）
[3] 不剔除，全量保留
```

**第二步：清洗确认——追加规则**

```
✅ 已确认剔除规则：作答时间 < 40s，剔除 XX 条，剩余 XX 条

还有其他清洗规则吗？例如：
・某题回答了「XXX」的剔除
・某题未作答的剔除
・其他自定义条件

[1] 没有，直接进入分析

[2] 有，我来描述
```

**第三步：推送题目列表 + 分析菜单**

```
📋 问卷解析完成
├─ 有效样本：XX 条
├─ 题目数：XX 题
└─ 可用分析：基础分析 / 交叉分析 / 子群分析 / 开放题归纳

题目列表：
┌──────┬────────┬──────────────────────────────┐
│ 编号 │ 题型   │ 题目                         │
├──────┼────────┼──────────────────────────────┤
│ Q1   │ 多选   │ （题目文字节选）             │
│ Q2   │ 矩阵   │ （题目文字节选）             │
│ ...  │        │                              │
└──────┴────────┴──────────────────────────────┘

下一步：
[1] 全部基础分析（推荐，跑所有单选/多选/矩阵/NPS题）

[2] 指定题目分析（告诉我题号）

[3] 交叉分析

[4] 开放题归纳
```

### 阶段N：每完成一个任务后

每完成一个阶段，主动推送菜单：

```
✅ 已完成：XXX（如：全部基础分析，共 XX 张表）
📄 结果文档：https://km.sankuai.com/collabpage/XXXXXXXXX

─── 还可以继续 ──────────────────────────────────

[1] 基础分析 ── 跑所有单选/多选/矩阵/NPS 题

[2] 交叉分析
    [2-1] 指定分析：「QXX × QXX」或「QXX 按某维度分组」
          多选题做维度需指定选项，如「Q6 × Q1-抖音」
    [2-2] 全量扫描：跑所有题 × 所有背景维度，自动找显著差异，发摘要
    [2-3] 通用背景维度：跑所有题 × 本问卷背景题
          （如：性别 QXX / 年龄 QXX / 收入 QXX / 使用频率 QXX，根据实际问卷动态填入）

[3] 子群分析 ── 输入格式：「只看 Q18=独立门店」

[4] 开放题归纳 ── 可分析：QXX / QXX（已完成的标注 ✅）

[5] 结束
─────────────────────────────────────────────────
```

## 交叉分析——全量扫描流程

用户选 [2-2] 或 [2-3] 时：

**第一步：告知计划，询问追加**
```
准备跑以下交叉分析：

维度题（根据实际问卷填入）：
・QXX 性别
・QXX 年龄
・QXX 使用频率
・QXX 个人月收入
・QXX 所在城市

被分析题：所有单选 / 多选 / 矩阵 / NPS 题

差异判断阈值：
・NPS 题：两组差值 > 10
・单选/多选：某选项占比差 > 15%
・矩阵：某子项均分差 > 0.5

你还想追加哪些交叉分析？

[1] 没有，直接跑

[2] 我来补充
```

**第二步：发摘要，用户决定写不写文档**
```
交叉分析完成，发现以下显著差异：

・QXX × QXX：A组 XX vs B组 XX，差值 XX
・QXX × QXX：某选项 A组 XX% vs B组 XX%
...

共发现 XX 组显著差异。

要把哪些写进文档？

[1] 全部写入

[2] 我来指定（告诉我题号）

[3] 都不需要，只要这个摘要
```

## 同类型题聚合提示

发现多道同类型题（NPS/满意度矩阵）时，分析前主动询问：

```
检测到 X 道 NPS 题（QXX / QXX / QXX...），是否合并成一张汇总表展示？

[1] 合并展示（一张总览表，各维度并排对比）

[2] 分别展示（每题单独一张表）
```

适用：多道 NPS 题、多道满意度矩阵题（同一量表）。
单选/多选/开放题默认分别展示。

## 技术实现

- 读文件：`openpyxl`（xlsx）或 `csv` 模块
- 作答时间计算：`提交时间 - 打开时间`，单位秒
- 输出文档：通过 `oa-skills citadel` 写入学城
- 结果文档父文档：由用户指定，或默认挂在问卷分析专用目录下

## 菜单格式规则

在大象等即时通讯场景，每个选项必须单独一行，不能连排：

✅ 正确：每个 [N] 选项单独一行，选项间空一行
❌ 错误：`[1] 基础分析 [2] 交叉分析 [3] 开放题 [4] 结束`（连排）
